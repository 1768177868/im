多客服系统接入示例

方式一：使用客服按钮组件（推荐）

在您的网站中嵌入客服按钮，点击后弹出聊天窗口。

1. 自动分配最闲的客服

<!-- 引入客服按钮组件 -->
<script src="https://your-domain.com/customer-service-button.js"></script>
<script>
  window.CUSTOMER_SERVICE_API_URL = 'https://your-api-domain.com';
</script>

2. 指定客服ID

<!-- 指定客服ID为1 -->
<a href="https://your-domain.com/button.html?api_base_url=https://your-api-domain.com&admin_id=1" target="_blank">联系客服</a>

3. 直接打开聊天页面

<!-- 自动分配 -->
<a href="https://your-domain.com/chat.html?api_base_url=https://your-api-domain.com" target="_blank">在线客服</a>

<!-- 指定客服 -->
<a href="https://your-domain.com/chat.html?api_base_url=https://your-api-domain.com&admin_id=1" target="_blank">联系客服1</a>

方式二：使用原生JavaScript SDK

使用提供的 customer-service.js SDK，完全自定义界面。

<script src="customer-service.js"></script>
<script>
  CustomerService.init({
    apiBaseUrl: 'https://your-api-domain.com',
    adminId: '1', // 可选，指定客服ID；不传则自动分配
    onMessage: function(message) {
      console.log('收到消息:', message);
    },
    onConnect: function() {
      console.log('连接成功');
    }
  });
  
  // 发送消息
  CustomerService.sendMessage('你好');
</script>

方式三：直接调用API

完全自定义实现，直接调用后端API接口。

// 1. 注册访客
fetch('https://your-api-domain.com/api/visitor/register', {
  method: 'POST',
  headers: {'Content-Type': 'application/x-www-form-urlencoded'},
  body: 'visitor_id=visitor123'
})
.then(res => res.json())
.then(data => {
  // 2. 创建会话（自动分配或指定客服）
  return fetch('https://your-api-domain.com/api/visitor/conversations', {
    method: 'POST',
    headers: {'Content-Type': 'application/x-www-form-urlencoded'},
    body: 'visitor_id=visitor123&admin_id=1' // admin_id可选
  });
})
.then(res => res.json())
.then(data => {
  console.log('会话创建成功:', data);
});

URL参数说明

  • api_base_url: API服务器地址（必填）
  • admin_id: 指定客服ID（可选，不传则自动分配最闲的客服）
  • visitor_id: 访客ID（可选，不传则自动生成）
  • conversation_id: 会话ID（可选，用于继续之前的会话）
  • position: 按钮位置（可选，bottom-right/bottom-left/top-right/top-left）

响应式设计

聊天窗口和按钮组件已自动适配PC和移动端：

  • PC端：固定宽度800px，居中显示
  • 移动端：全屏显示，优化触摸操作
  • 自动检测设备类型，调整UI布局
